# M0B1Li7Y

Small browser-based mobility routine app built from the preserved image assets.

## Features
- 12-step guided flow with cues and visuals
- Countdown timer for timed steps
- Untimed reps step (`Counter Pushups`)
- Controls: `Start`, `Pause/Resume`, `Back`, `Next/Finish`, `Reset`
- Session completion counter saved in `localStorage`

## Kept assets
- Routine images in `img/`
- App/icon images in `icons/`

## Run locally
```bash
python3 -m http.server 4173
```

Open http://localhost:4173
